# Uranus v5 — 日常编辑体验修复与增强需求

> 日期：2026-10-26。状态：需求与优先级基线，已同步本轮后续讨论和修改；实施和验证记录见 [implementation-v5.md](implementation-v5.md)，本文不代表全部发布门槛已通过。
> 来源：最初 13 项使用反馈及后续交互调整。第 2 节中的旧行为描述为立项时观察；最终行为以各章节及第 13 节变更追踪为准，不把旧描述当作当前实现。
> 基线：沿用 plan_v1–v4；只调整本文明确列出的体验与内容能力。继续采用 Cloudflare Worker + D1/R2 bindings，不新增离线功能、Service Worker 或网页令牌管理。

## 1. 优先级与交付原则

- **P0：保存可靠性。** 优先定位并消除合法操作产生非法表格、进而阻断保存的问题；未支持操作不得先修改正文，再到保存时失败。
- **P1：本轮核心交付。** 高频阅读、编辑、保存、粘贴和搜索体验，要求本轮完整实现并回归。
- **P2：后续增强批次。** 行号、系统风格窗口标题栏、小号文本，可以在 P1 稳定后交付；仍属于 v5，不代表取消。
- 优先级不等于开发难度。表格富文本涉及 schema 兼容，不能因为界面容易添加按钮而跳过数据设计。
- 不改变现有工具栏按钮的相对顺序，不重新分组；确需新增按钮时插入相邻语义位置，窄屏仍横向滚动。
- 移除输入斜杠触发的快捷菜单及其键盘拦截；`/`、`/table`、`/code`、`/h2` 等均作为普通文本，回车正常换行，方向键保持正常光标导航。表格、列表、代码块等使用现有工具栏入口。
- 未获授权不得在生产笔记上做破坏性测试；优先用本地测试数据复现。

## 3. 阅读密度与排版

### V5-01：行高和块间距

- 保留默认正文 14px 和用户已保存的字号偏好，不用整体缩小字体代替间距优化。
- 正文行高基线改为 `1.5`；相邻普通段落间距为 `0.5em`，通过单边 margin 控制，避免上下叠加。
- 列表项内普通段落 margin 为 0，列表项间距不超过 `0.25em`；单元格内相邻段落间距不超过 `0.25em`。
- 标题上下间距保留层级，不套用普通段落的零间距；代码块行高采用 `1.45`，文字不能重叠或裁切。
- Enter 仍创建段落，Shift+Enter 仍创建软换行；不得批量删除用户原有空段落，或为视觉调整改写正文 JSON。
- 验收：中英文、长段落换行、连续段落、软换行、空段落、列表与单元格均检查；14/16/18/20px 字号和浏览器 200% 缩放下仍清晰可读，历史预览与正文一致。

### V5-03：统一左边界

- 顶层普通段落、标题、表格外边框、代码块外边框和引用左侧装饰线使用同一内容起始线。
- 表格行列手柄、行号使用辅助区域，不以扩大表格正文左 margin 的方式挤偏内容；辅助区域不制造整页横向滚动。
- 行操作“三点”按钮和插行按钮位于单元格外侧，不遮挡首列文字、光标或文本选择；顶部表格菜单与插列按钮的点击区域不得冲突。
- 列表标记/复选框位于统一起始线内侧，列表文字采用统一悬挂缩进（基线 `1.5em`），换行与该项文字起点对齐。不得为了让文字齐左把标记挤出编辑区域。
- 嵌套列表保留必要层级缩进；引用文字保留边线后的内边距；单元格内部使用自身内容边界，不强行贴齐页面边界。
- 验收：同一笔记连续排列段落、列表、表格、引用、代码块，桌面/320px、宽版/阅读宽度下逐一比较；表格局部横向滚动仍可用。聚焦首列输入时行操作按钮不与单元格重叠，行菜单、插行及顶部表格菜单仍可点击。

### V5-04：笔记列表文字层级

- 列表标题基线 14px、字重 600；摘要 12px、行高 1.4；时间维持 11px。
- 摘要默认保留单行省略，标题与摘要间距约 4px，不扩展成多行卡片。
- 摘要不随“编辑器字号”设置变化；高亮搜索片段使用同一摘要字号。
- 保留现有标题/摘要重复去重，浅深主题和选中背景下均可读；不以降低到难以辨认的透明度来弱化摘要。

### 后续补充：工作区字号与控件

- 工作区基础字号统一为 14px，文件夹列表、全局搜索框、笔记内搜索框及操作按钮、顶部文件夹下拉框均继承该基线；摘要和保存状态保留 12px，时间保留 11px。
- 正文继续使用 14/16/18/20px 用户偏好；品牌、标题等保留自身层级，不将所有文字强制设为同一字号。
- 星标按钮选中时显示实心五角星，取消后恢复空心，并通过按下状态表达是否选中；此处指笔记星标，不是正文荧光高亮按钮。
- 顶部文件夹与设置面板下拉框统一箭头样式，箭头距右边缘约 10px，右侧预留 32px 空间，避免贴边或遮挡选项文字。窄屏仍需保证控件和完整选项可用。

### 后续补充：空待办项输入区域

- 待办项复选框保持固定宽度，右侧文字容器撑满剩余可用宽度，空段落至少保留一行高度（1.5em）。
- 点击空待办项的复选框右侧应定位输入光标并可直接输入；Enter 创建的新待办项同样适用，不用插入占位字符撑开布局。
- 验收覆盖正文和表格单元格：从已有待办 Enter 新建空项，焦点移走后点击空白文字区，确认选区落在空段落中，输入后文字仍属于该待办项。

## 4. 自动保存与快捷键保存（V5-02）

- 顶部元信息栏不提供独立“保存”按钮，桌面和窄屏均保留保存状态提示；原有置顶、星标、文件夹、历史、更多按钮相对顺序不变。
- 本地草稿继续存入 IndexedDB，停止输入 800ms 后保存，持续输入时最多每 3 秒保存一次；不将正文改存 localStorage。
- 有待同步改动时，默认每 30 秒远程同步一次；持续输入不延后已经启动的同步计时，空闲且无改动时不发送保存请求。设置面板支持 5–300 秒整数间隔，仅此浏览器生效，恢复默认偏好时恢复 30 秒。
- Cmd/Ctrl+S、切换笔记立即提交当前标题、正文和待提交元数据；进入后台尽力提交，关闭页面不保证同步成功。普通编辑失焦仅写入本机草稿，不绕过远程间隔。置顶、星标、移动文件夹等显式元数据操作仍即时提交，复用现有串行队列、revision 和 operation_id。
- 状态区分本机暂存中、已存本机待同步、正在远程保存与服务器确认；本机写入失败不得显示已存本机。网络恢复后重试暂时性失败，401 和 409 不自动循环重试或强制覆盖。
- Cmd/Ctrl+S 阻止浏览器“保存网页”；仅在当前笔记可编辑且不处于其他输入对话框时接管，IME 组合输入期间不提前提交未完成的组合文本。
- 无改动显示“已保存”状态；进行中显示保存进度，重复快捷键不产生重复提交。保存期间新输入仍保持待提交，不被旧响应覆盖。
- 上传中的图片不能被误报为已写入正文；可以提交已有文本，但显示独立上传状态，全部内容成功确认前不能宣称全部保存完成。
- 失败可以重试；409 使用既有冲突处理，不强制覆盖。只读/回收站不提供修改性保存操作。
- 验收：800ms 本机防抖、持续输入 3 秒落盘、默认 30 秒远程周期、间隔修改及记忆、失焦不触发远程请求、快捷键和切换笔记立即同步、保存时继续输入、标题与正文连续修改、断网及联网重试、401、409、本机存储失败和退出提交预算；保存状态与实际保存位置一致，桌面和窄屏均无独立保存按钮。

## 5. 图片复制粘贴（V5-05）

- 支持通过系统复制截图/图片后，在正文和允许图片的表格单元格中 Cmd/Ctrl+V 粘贴；优先读取真实粘贴事件，不在页面加载时读取剪贴板。
- 纯图片剪贴板即使没有附带文字或 HTML 也必须可上传和插入；编辑器返回空文本片段时按空集合处理，不因对 null 调用数组方法而中断粘贴。
- 用户复制笔记内图片后可粘贴到本笔记或同一实例的其他笔记。同笔记可复用附件引用；跨笔记必须生成目标笔记专属附件，不能直接引用源笔记的私有 attachmentId。
- 图片上传沿用当前 MIME、文件大小、魔数、安全校验和私有 R2 API；不增加公开桶、第三方上传服务或浏览器直连 R2。
- 同次粘贴同时带文件和 HTML 中的同一图片时只插入一次；多张图片按原顺序插入，提供进度、失败与重试反馈。重试不能重复插入已成功图片。
- 记录并随编辑映射插入位置；切换笔记、删除插入位置或取消后不得误插入当前另一篇笔记。失败保留原有正文，不产生永久的破图节点。
- 只含外部图片 URL 的 HTML 不自动下载；提示无法直接导入该图片并提供上传指引。普通文本/HTML 粘贴继续按既有安全规则处理，不能因图片分支吞掉文字。
- 若提供“复制图片”按钮，仅在用户点击后尝试系统支持的剪贴板格式，权限拒绝或不支持时明确提示；不得声称所有浏览器都能写入同一图片格式。跨应用复制优先验证 PNG/截图，格式转换不得静默丢失 GIF 动画。
- 不支持跨部署实例自动继承私有图片权限；不新增任意远程 URL 抓取代理。
- 验收：系统截图、PNG/JPEG、同笔记/跨笔记、表格内、多图、混合文本、上传失败重试、只读、切换笔记、源笔记删除后目标图片和历史版本仍可读。单独覆盖正文和表格单元格中的纯图片粘贴（无文字、无 HTML），确认只插入一次且保存刷新后仍可读。

## 6. 超链接（V5-06、V5-12）

### 6.1 自定义对话框

- 用应用内对话框替换原生 prompt，包含“显示名称”“链接地址”“保存/插入”“取消”，已有链接提供“移除链接”（保留文字）。
- 选中纯文本时默认用选区作为名称；光标在已有链接中时读取完整链接范围及其名称、地址；无选区时可输入名称，为空则用地址作为显示文字。
- 保存名称变更只替换当前链接文字，不覆盖相邻内容；只改 URL 时保留原文字格式。结构化跨块选区不做隐式拼接，提示缩小到单个文本块。
- 保持现有 `http`、`https`、`mailto` 协议白名单；禁止 javascript/data/file 等协议。验证失败在字段旁提示，不关闭对话框、不清空输入。
- 打开时保存编辑选区；取消/Escape 不改正文，关闭后恢复合理焦点。笔记切换后废弃旧目标，不能把链接写入另一篇笔记。
- 支持键盘 Tab、Enter 确认、Escape 取消；IME 组合输入时 Enter 不误确认，窄屏内所有控件可达。

### 6.2 点击访问与编辑区分

- 阅读模式：单击链接，在新页面/浏览器窗口打开，不替换当前笔记。
- 编辑模式：普通单击仍用于定位文字，同时出现紧邻链接的轻量操作条，至少包含“打开链接”“编辑链接”“移除链接”；点击“打开链接”即可访问。
- 链接操作弹层使用紧凑布局：桌面宽度不超过 240px，操作文字 13px；正文已展示链接文字，弹层不重复显示网址预览。操作带图标，“移除链接”分隔并使用警示色。沿用主题变量、键盘关闭和焦点恢复，窄屏保留底部面板及至少 44px 操作高度。
- 编辑模式支持 Cmd/Ctrl+单击直接打开，并用提示说明；移动触屏使用操作条，不依赖修饰键。拖选链接文字时不得误打开。
- 新页面使用 `noopener noreferrer`；外部链接在 PWA 中的具体承接方式由浏览器控制，但不能丢失当前编辑现场。
- 验收：自定义名称、地址编辑、取消、非法协议、选区格式、长名称、只读点击、编辑模式访问、触屏操作及新窗口安全属性。

## 7. 表格可靠性与增强

### V5-09B：结构错误与保存阻断（P0）

- 首先复现用户遇到错误的具体路径：插删行列、最后一格 Tab、粘贴外部表格、列表/引用转换、撤销重做及保存后重载。
- 对当前已经支持的合法操作，编辑器每次提交的表格都必须为矩形且每行包含相同数量的单元格。保留服务端结构校验，不把错误改成静默保存。
- 未开放的格式操作应在执行前禁用并解释原因；不能先生成服务器拒绝的内容，再让整篇笔记反复保存失败。
- 对无合并单元格的外部表格粘贴，可在客户端为短行补空单元格形成矩形；不得丢弃多出的单元格或重排原内容。超出尺寸/正文预算则拒绝本次插入并提示，原文保持不变。
- 含 colspan/rowspan 的表格本版不扩展支持合并单元格；明确提示不支持，不默默截断或将内容挪错单元格。
- 已有异常文档先保留可导出的原始 JSON，允许用户选择有预览的修复；不在读取时静默改写历史数据。
- 验收：每个复现路径都有回归用例；合法编辑可保存、刷新后行列一致；非法输入有明确提示且不会损坏原文和历史。

### V5-09A：单元格富文本（P1）

- 在已有段落/图片基础上，支持无序列表、有序列表、待办列表、引用和代码块；与正文复用命令，不实现一套独立的单元格编辑器。
- 单元格内不开放嵌套表格、合并单元格或任意 HTML。保留现有深度、节点数量和正文体积限制；列表/引用只能包含新 schema 明确允许的结构。
- 列表退出、引用退出、代码块退出均能在当前单元格继续输入；不能意外把内容移到相邻单元格或表格外。
- Tab 在普通单元格仍按表格规则导航；列表缩进提供明确按钮/快捷方式，代码块有单独缩进规则，避免同一按键同时插列和缩进。
- 格式工具栏在“待办”后增加“增加缩进 / 减少缩进”两个独立按钮，保留原有按钮相对顺序。适用于正文及单元格内的无序、有序、待办列表：增加一级嵌套，或提升一级（最外层减少缩进退出列表）。按最内层列表项类型复用编辑器命令，支持撤销/重做并走原保存队列；不能缩进的首项、非列表内容及只读状态按能力禁用，不新增段落缩进属性。代码块仍使用 Tab/Shift+Tab。
- 行列新增、删除、复制、清空及撤销时完整保留这些块和图片引用；表格水平/垂直对齐作用对象不改变。
- 本需求必须与第 11 节 schema 兼容方案一起交付，前后端、历史预览、导入导出及备份恢复同时验证。

### V5-07：辅助行号（P2）

- 表格菜单增加“显示行号”开关，默认关闭；作为当前浏览器的 UI 偏好应用于所有表格，不修改笔记 revision，不增加正文数据列。
- 行号从 1 开始，包含表头行，始终对应物理行顺序；插删行后自动更新，不提供业务记录编号或排序能力。
- 行号位于表格左侧辅助区，随对应行高度变化；不得覆盖行操作手柄、首列文字或制造整页溢出。横向滚动时仍能识别对应行。
- 行号不可编辑，不计入搜索、复制、导出和附件引用；隐藏后恢复原表格宽度布局。
- 验收：有无表头、多行高、列表/图片单元格、插删行、宽表滚动及窄屏；开关不触发保存。

## 10. 单条笔记搜索定位（V5-13）

- 笔记内搜索在浏览器对当前标题和正文运行，高亮及箭头定位不发送搜索请求、不触发保存；与左侧通过服务器查询笔记列表的全局搜索区分。
- Cmd/Ctrl+F 打开笔记内搜索，提供搜索词、上一个、下一个、当前序号/总数和关闭；Enter/Shift+Enter 切换，零结果显示 0/0 并禁用切换。
- 范围包含顶部标题投影和正文可见文字，包括列表、引用、表格、代码块；不搜索 URL、隐藏属性、附件字节或辅助行号，不包含替换功能。
- 使用不区分大小写的字面匹配，不解释正则表达式；同一文本块内跨加粗/链接等内联文本节点仍能命中，不跨段落或单元格拼接匹配。Unicode 文本位置映射必须正确。
- 标题命中应定位并选中标题输入区对应文字；正文命中高亮并滚动到编辑器可视区域，不能被顶栏/搜索栏遮挡；宽表和代码块命中时还需滚动相应局部横向容器。
- 输入搜索词时保持输入框焦点，不因滚动或正文选区变更中断继续输入；标题命中可以更新选择范围并标示“标题”，不能强行抢走搜索输入焦点。
- 按标题、正文顺序循环定位，每次切换都让当前结果可见；当前结果样式明显区别于其他命中。
- 只有 `1/1` 个命中时，上下箭头仍可将手工滚离的视图重新定位到该命中。长代码块应滚动到具体高亮文字，不以整个代码块居中替代命中定位。
- 内容编辑后及时重算数量和位置，旧计数不得被缓存值覆盖；切换笔记清除旧位置。异步渲染与图片加载后仍能保持当前结果可见，不无限滚动纠偏。
- 搜索、选择命中和滚动不写入保存队列、不增加 revision；只读模式同样可以查找。关闭后恢复合理编辑焦点，不意外替换选中文字。
- 验收：长笔记远端命中、跨 mark、重复词、中文/emoji、顶部标题、多行与宽表单元格、代码块、只读、连续编辑后数量更新及搜索栏不被抢焦点。
