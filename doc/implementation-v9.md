# v9 本地实施与验证记录

日期：2026-11-02。对应需求为 `plan_v9.md` 的 V9-01 至 V9-10。本轮未增加 content schema 版本或数据库迁移；依赖变更仅为按需语言高亮使用的 `lowlight` 与 `highlight.js`。

## 已实施功能

- V9-01：查找栏增加单个替换和全部替换；正文替换复用既有匹配区间，标题匹配只查找不替换；全部替换为单个事务，支持撤销/重做、只读回退和组合输入守卫。
- V9-02：笔记列表、搜索和回收站列表响应派生正文顺序中的第一幅当前图片；客户端通过既有鉴权附件接口懒加载缩略图，下载失败静默隐藏。首图删除或正文顺序改变后随保存更新。
- V9-03/V9-04：代码块支持 JSON 格式化、注册语言高亮和语言 Popup；高亮只生成装饰，不修改文档，未知语言及超过 50,000 字符的代码块降级为纯文本。格式化、语言更新参与正常撤销和保存。
- V9-05：工具栏和斜杠菜单可插入本地日期或日期时间纯文本；只读及代码块内禁用工具栏入口。
- V9-06：无 HTML 的多行纯文本粘贴可保守识别标题、引用、列表、待办、围栏代码、分隔线、GFM 表格及常见行内标记。URL、JSON/代码、短单行和 HTML 剪贴板维持原路径；转换结果先通过当前 schema 校验。data URI 图片先插入独立占位并串行上传为私有附件，失败降级为字面链接；外链和相对图片不创建图片节点。
- V9-07：空选区 `Mod-C` 复制当前文本块，代码块内复制当前物理行，并附加换行；已有选区继续使用浏览器原复制路径。
- V9-08：笔记菜单隐藏重复标题但保留 dialog 的无障碍名称及标题占位，其他 Popup 标题保持显示。
- V9-09：Popup、移动端底部弹层、通知、设置抽屉和居中对话框加入 80–200ms 的 transform/opacity 进入动效，通知支持退出动效；微交互仅过渡背景色或透明度，并支持 `prefers-reduced-motion`。
- V9-10：空段落开头的斜杠命令支持过滤、方向键、Enter、Esc 与鼠标操作，复用工具栏命令；执行后一次撤销可恢复输入的 `/xxx`。

## 审查修复

- 修复标题命中时“全部替换”仍可用、单个替换索引偏移和组合输入 Enter 误触发问题。
- 修复 Markdown 多图异步上传乱序、相对链接被错误改写为当前站点 URL、嵌套粗斜体闭合、非表格管道文本导致解析游标不前进等边界；补充 data URI 大小限制和整体 schema 回退。
- 修复代码操作栏闭包读取旧文本、语言切换未使用统一 Popup、格式化/斜杠命令撤销边界、斜杠菜单过滤后选中项越界，以及笔记链接缺少纯文本投影导致复制当前行不完整。
- 缩略图查询按保存时稳定重建的当前附件引用顺序选择首图，并以反向上传/正文顺序的集成用例验证，不依赖附件上传顺序。
- 通知退出不再瞬时卸载；弹层定位用例等待进入动画结束，并验证 reduced-motion 下无可见延迟。
- 所有 E2E 统一使用本地登录 fixture；套件串行运行，避免共享的受限 admin 测试账号形成并发登录风暴，同时仍保留真实 `Retry-After` 处理。

## 本地验证

- `npm run typecheck`：通过。
- `npm test`：43 个测试文件、136 项单元及 Workers 集成测试全部通过。
- `npm run test:e2e`：单次完整 Chrome 串行回归 81/81 通过，耗时约 10.5 分钟。
- `npm run build`：Worker 与客户端构建通过；仍有客户端主 chunk 超过 500 kB 的既有警告。
- `git diff --check`：通过。
- 高亮体积：同一依赖环境、同一本地 Wrangler 配置下，以 `git HEAD` 为基线执行生产构建并用 `gzip -9c` 测量唯一客户端 JS；基线 332,594 字节，当前 359,026 字节，增量 26,432 字节，低于 40KB 目标。
