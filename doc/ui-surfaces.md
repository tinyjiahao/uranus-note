# 对话框与控件样式盘点

2026-10-28。按源码中的独立挂载入口计数，菜单子页和同一表单的新增/编辑模式不重复计数。

## 自绘界面：16 个入口

| 类别 | 入口 |
| --- | --- |
| 共用 Popup 的 13 个入口 | 笔记排序、工作区更多、笔记操作、附件操作、笔记互链、标签插入/编辑、链接操作、ZIP 导出、段落样式、笔记大纲、文本颜色/突出显示、插入表格、表格操作（含行/列/单元格子菜单） |
| 原生 dialog 元素的 2 个自绘表单 | 设置、切换账号 |
| role=dialog 的 1 个自绘表单 | 插入/编辑超链接 |

另有版本历史侧面板 1 个、登录/注册页面表单；本次一并对齐基础控件样式，不计入上述对话框数量。

## 浏览器原生窗口：13 个调用点

- confirm 8 处：未同步修改的同步/放弃、永久删除笔记、删除文件夹、清空回收站、恢复偏好、恢复历史版本、删除非空表格。
- prompt 2 处：新建文件夹、管理文件夹。
- alert 3 处：默认文件夹删除提醒、文件夹操作错误、Markdown 导入错误。

原生窗口由浏览器绘制，网页 CSS 无法调整。本次保留其行为；系统文件选择器、安装提示也不属于可样式化的应用弹层。

## 共享标准

`src/ui-surfaces.css` 在基础布局样式后加载，是自绘面板视觉规范的统一入口。颜色复用现有深浅主题变量；正文 13px、标题 14px、辅助信息 12px；桌面表单控件 32px，触屏/窄屏 44px。字段背景、边框、圆角、主按钮、次按钮、错误颜色、遮罩统一。色块、标题层级预览和笔记正文不强制套用表单高度或字号。

标签/颜色弹层维持紧凑宽度，设置与账号面板保留容纳长表单的宽度；尺寸差异按内容用途保留。新组件应使用共享变量，不另设一套按钮/输入框的颜色与尺寸。打印样式不受这份屏幕专用规范覆盖。

2026-10-28：新增“更多格式与插入” Popup（工具栏 +），当前自定义弹层入口总数为 17；复用共享字号、颜色和控件高度。
