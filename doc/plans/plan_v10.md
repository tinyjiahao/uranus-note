# Uranus v10 — 移动端导航、Safari 兼容与图片预览

日期：2026-11-08。V10-01 至 V10-09 已发布到生产。iPhone 主屏幕 PWA、真实输入法和剪贴板仍待实机验收。

## V10-01 移动端默认选中第一个笔记本

首次打开手机端首页时，列表原先停在「请选择笔记本」，用户必须手动选择才能浏览笔记。

- 在宽度不超过 767px 的首页，笔记本加载成功后，按列表顺序默认选中第一个笔记本并加载其中的笔记。没有笔记本时显示「全部笔记」。
- 自动选择仅在尚未选定范围时执行。用户切换笔记本、星标或回收站后，从笔记返回列表仍保留当前范围。直接打开笔记链接时，列表范围由该笔记决定。
- 实现在 [Workspace.tsx](../../src/app/Workspace.tsx)。

## V10-02 编辑长笔记时保留顶部操作入口

手机上编辑长笔记时，软键盘可能缩小或移动可见区域，把顶部导航和格式工具栏带出屏幕，导致返回、更多菜单及撤销入口无法操作。

- 初版跟随 `VisualViewport` 的高度与布局视口内偏移。上线后反馈 iOS 主屏幕 PWA 在编辑长笔记时仍会丢失顶栏，收起软键盘后也可能无法恢复。
- 后续改为在未缩放时使用 `VisualViewport.height` 和文档坐标 `pageTop` 定位移动端编辑区，监听页面及可见视口的滚动和尺寸变化。
- 正文区域独立滚动。顶栏和格式工具栏留在正文滚动区域之外，使返回列表、更多菜单和撤销在编辑期间保持可达。
- 实现在 [Workspace.tsx](../../src/app/Workspace.tsx) 和 [styles.css](../../src/styles.css)。

## V10-03 Safari 笔记列表请求兼容

部分 Safari 环境缺少 `AbortSignal.any()`。原实现会在发送带取消信号的笔记列表请求前抛错，表现为会话和文件夹已加载、笔记列表加载失败。

- 使用 `AbortController` 转发调用方取消信号，并保留账号切换时的请求取消。请求完成后移除监听。笔记查询和附件字节下载共用这条路径。
- Cloudflare Web Analytics 脚本曾触发 Safari CSP 警告。该脚本不是笔记应用的运行依赖，项目继续使用同源脚本策略。白屏原因尚未在 Safari 实机确认。
- 实现与兼容回归见 [client.ts](../../src/api/client.ts) 和 [api-client.test.ts](../../tests/unit/api-client.test.ts)。

## V10-04 图片预览操作与移动端适配

- 参考 Confluence 布局，标题位于左上角，关闭位于右上角。底部中央依次为缩小、放大、复制，右下角显示缩放百分比，点击可恢复适屏大小。
- 默认 100% 表示适合预览区域的大小，基准尺寸不超过原图。每次调整 25 个百分点，范围为 50%～400%，宽高等比缩放。
- 图片超出预览区时可横向和纵向滚动。操作栏独立于图片滚动区，保留至少 44px 的触控目标和屏幕安全区。
- 复制将图片以 PNG 写入系统剪贴板，预览内提示成功或失败。通过原有私有附件地址读取图片。支持关闭按钮、Esc 及点击图片外的预览空白区域关闭。
- 实现见 [ImagePreview.tsx](../../src/components/editor/ImagePreview.tsx)、[inlineImage.tsx](../../src/components/editor/inlineImage.tsx) 和 [styles.css](../../src/styles.css)。

按用途划分为 `plans/`、`implementation/`、`operations/`、`reference/` 和 `reviews/`。新增 [文档索引](../README.md)，同步更新仓库中的路径引用并检查 36 个本地链接。

## V10-06 界面中英文切换

- 登录页和设置提供简体中文、English 两个选项。默认简体中文，选择后立即更新界面及页面语言标记，并在当前浏览器保存偏好。
- 翻译覆盖登录、工作区、设置、编辑器工具栏与菜单、图片和附件预览等应用界面。切换时保留当前笔记、编辑器和草稿。已有笔记正文、标题、文件夹和附件名称保留原文。
- 文案集中在 [messages.ts](../../src/state/messages.ts)，语言偏好见 [locale.ts](../../src/state/locale.ts)。不新增依赖、数据库迁移或内容格式。
- 本地浏览器验收覆盖登录前切换、刷新恢复语言、打开笔记后从设置切回中文，以及当前编辑器与内容保留。

## V10-07 最近打开与恢复阅读位置

- 桌面侧栏和移动端笔记本选择器提供「最近打开」，按打开时间倒序展示最多 20 篇笔记，支持在这个范围内搜索。列表从服务端读取最新摘要并沿用账号鉴权，忽略回收站、已永久删除或无权访问的笔记。
- 当前浏览器按账号保存笔记 ID 和正文纵向滚动位置。重新打开笔记或刷新时恢复正文位置，附件加载引起布局变化时可继续定位。操作正文后停止自动定位。历史版本预览使用独立滚动区域。
- 语言与记录均保存在浏览器偏好中，正文、标题和附件仍按原路径读取和保存。

## V10-08 移动端编辑稳定性补充

- 将连续视口滚动和尺寸事件合并到动画帧。编辑区失焦、页面恢复和应用回到前台时重新同步可见视口，并在键盘动画结束后复测位置。
- 格式工具栏聚焦时只调整自身的横向滚动，避免间接滚动整个页面。返回列表前结束当前焦点并触发保存，页面离开时沿用现有本机草稿和尽力同步路径。
- Chrome 移动尺寸覆盖视口恢复、返回、撤销和阅读位置。iPhone 主屏幕 PWA 与真实输入法仍需实机验收。

## V10-09 超长代码块整块操作

- 编辑模式下，展开和折叠的代码块均提供「选中整块」与「删除代码块」。选中后可按 Backspace 或 Delete 删除，也可直接点击删除按钮。一步撤销可恢复完整代码及折叠状态。
- 折叠时从首行显示，只渲染预览区域所需的行号。只读模式隐藏整块选择和删除按钮。
- 4,159 行代码块的选择、键盘删除、按钮删除、撤销与只读保护已通过 Chrome 回归。折叠代码搜索和高亮相关回归也通过。用例见 [v8-regressions.spec.ts](../../tests/e2e/v8-regressions.spec.ts) 和 [v9.spec.ts](../../tests/e2e/v9.spec.ts)。

## 表格间距试验与撤销

曾尝试缩小表格上下留白，在鼠标悬停或表格激活时扩展顶部空间。实用反馈显示鼠标移入、移出会导致表格上下跳动，因此已撤销该方案，恢复原有固定间距。
