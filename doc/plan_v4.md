# Uranus v4 — 可安装独立窗口最小改造需求

> 日期：2026-10-25。状态：已实现，真实 macOS Chrome 安装与 Dock 启动待人工验收（见 implementation-v4.md）。
> 基线：在现有 React SPA + Cloudflare Worker 应用上增量改进；未变更的约束继续遵循 plan_v1、plan_v2、plan_v3 和 AGENTS.md。
> 本文中的 Dock 指 macOS 程序坞，不是 Docker。

## 1. 目标与范围

用户通过桌面 Chrome 安装 Uranus 后，可以从 Dock 中的独立图标启动，在独立窗口中使用笔记，不必每次打开浏览器并与其他网站标签页混在一起。

本版仅提供应用安装元信息、安装入口与指引、独立窗口运行支持。应用仍需联网，不建设离线应用或原生桌面客户端。

### 1.1 必须交付

- Web App Manifest，明确应用身份、名称、图标、启动地址和独立窗口模式。
- 清晰的安装图标及页面声明。
- 设置中的安装入口；无法触发安装提示时提供手工安装指引。
- macOS Chrome 安装、从 Dock 启动、独立窗口使用与现有笔记功能回归验收。

### 1.2 明确不包含

- Service Worker 的新增或注册、离线页面、资源预缓存、Cache Storage、离线笔记/附件缓存。
- 后台同步、后台上传、推送通知、通知角标、文件关联、分享目标及协议处理器。
- Electron、Tauri、原生安装包、应用商店发布、自定义窗口标题栏或系统按钮。
- 更改 D1/R2 bindings、数据库表、内容 schema、API、令牌或会话期限。
- 完整手机 PWA 适配、所有浏览器安装支持、多实例窗口协调、强制接管网页链接。
- 自动固定 Dock 图标、保证所有外部笔记链接自动打开独立窗口。

保留已有 IndexedDB 草稿和失败重试机制，但不得将其描述为新增离线能力或完整离线保障。

## 2. 应用清单

新增公开静态资源 `public/manifest.webmanifest`，在 `index.html` 中通过 `rel="manifest"` 引入。

| 字段 | 要求 |
| --- | --- |
| `id` | `/`，同一部署 origin 下保持稳定；不得随版本号、笔记或登录状态变化 |
| `name` | `Uranus Notes` |
| `short_name` | `Uranus` |
| `description` | 简要说明联网笔记用途，不宣称支持离线 |
| `lang` | `zh-CN` |
| `start_url` | `/`，不包含笔记 ID、令牌、会话标识或安装追踪参数 |
| `scope` | `/`，覆盖首页、登录及笔记路由 |
| `display` | `standalone`；不使用 fullscreen 或自定义标题栏覆盖模式 |
| `theme_color` | 选用与现有 Uranus 品牌协调的颜色 |
| `background_color` | 与默认启动背景协调 |
| `icons` | 引用下节定义的同源安装图标 |

- Manifest 与资源 URL 不硬编码 `note.searchdiff.com`，使用以 `/` 开头的同源路径，保留现有根路径自部署方式；本版不新增子路径部署支持。
- 用户首次从安装图标正常启动时进入首页，未登录则由现有鉴权导航到登录页。浏览器/操作系统自行恢复上次窗口的行为不强行覆盖。
- 不请求持久存储权限，不增加安装追踪或遥测。

## 3. 安装图标与页面声明

- 沿用现有笔记图标设计，不新增品牌重设计需求。
- 提供 192×192 和 512×512 PNG 图标，manifest 中准确声明尺寸、类型及 `purpose: "any"`。
- 提供独立的 512×512 maskable 图标，主体位于安全区且背景铺满；不得仅将普通图标标记为 maskable。
- 提供 180×180 PNG Apple Touch Icon，替换当前页面的 SVG Apple Touch Icon 引用；不因此扩大到完整 iOS 适配。
- 保留网页 favicon；添加页面 `theme-color` 声明，与应用主题协调。浅色/深色下均不得出现不可辨认的图标。
- 图标在 Dock 中清晰、无异常裁切；窗口标题仍由现有应用/浏览器机制管理，不伪装原生客户端。

## 4. 安装入口与反馈

### 4.1 位置

在现有“设置 → 关于与部署”内增加“安装应用”小节，不增加常驻浮层，不改变编辑工具栏按钮及排序，不在用户编辑时自动弹出安装提示。

### 4.2 状态与行为

| 状态 | 展示和行为 |
| --- | --- |
| 普通浏览器窗口，收到可用安装事件 | 显示“安装 Uranus”；用户点击后调用浏览器原生安装提示 |
| 没有可用安装事件 | 显示“如何安装”及手工安装指引，不能显示点击无效的安装按钮 |
| 正在触发安装提示 | 防止重复点击；由用户在原生界面决定安装或取消 |
| 用户取消或提示失败 | 留在当前页面，保持笔记、焦点恢复能力和草稿；不反复弹出，恢复指引入口 |
| 当前处于 standalone 模式 | 隐藏安装按钮，显示“当前以独立窗口运行” |

- 安装事件仅保存在内存；使用后清除，不能重复调用已消费事件。
- 不将“没有安装事件”判断为“已经安装”，也不将用户接受提示直接当作系统安装完成。
- 可响应 `appinstalled` 更新当前页面提示；不得在 localStorage 中保存永久的“已安装”布尔值作为事实来源，以免卸载后状态失真。
- 安装相关事件监听须正确清理，避免 React 重挂载造成重复提示。
- 安装入口支持键盘访问，有明确可访问名称；状态变化提供适度反馈。

### 4.3 macOS Chrome 手工指引

1. 使用支持网页应用安装的 Chrome 打开当前部署地址。
2. 打开右上角菜单，进入“投放、保存和分享”中的“将网页安装为应用”；实际名称以当前浏览器版本为准。
3. 安装后打开 Uranus 独立窗口。
4. 在 Dock 中右键 Uranus 图标，选择“选项 → 在程序坞中保留”。

指引明确说明：固定 Dock 由用户操作，网页无法保证自动固定；没有该菜单时可检查浏览器版本或设备管理限制，仍可继续使用网页版。不因缺少安装支持阻断笔记功能。

## 5. 独立窗口与数据安全

- 正常运行时使用独立应用窗口，不显示普通浏览器的多网站标签栏；系统/浏览器的安全提示、窗口菜单不在应用控制范围内。
- 应用内切换笔记、搜索、编辑、设置等继续在当前窗口中完成，不为普通内部导航新开浏览器标签。
- 外部链接不替换正在编辑的笔记页面；需要新开页面时沿用安全链接策略，具体由系统浏览器承接。跨出 manifest scope 后是否显示浏览器安全 UI 由浏览器决定。
- 沿用现有 HttpOnly 会话。符合浏览器共享条件时复用登录；会话过期或密钥轮换后仍须登录，不承诺跨浏览器配置文件共享登录或永久免登录。
- 标题、正文、表格、图片、保存状态和草稿逻辑不变。关闭窗口不等于保存成功，不绕过服务端确认，不承诺强制退出后必然恢复未保存内容。
- 未联网时只保留原有网络失败反馈和已具备的草稿行为；冷启动失败可以使用浏览器默认网络错误页，不新增离线页面。
- 不缓存 `/api/*`、登录响应、私人笔记或附件；保留敏感 API 的 `Cache-Control: no-store`。

## 6. 构建、部署与更新

- React/Vite、Hono Worker、D1、R2 及同源 API 架构不变。生产使用现有 HTTPS 部署。
- Manifest、图标必须无须登录即可获取，响应为实际文件，不能错误返回 SPA 的 `index.html`；校验 manifest MIME 类型为 `application/manifest+json`。
- 保持现有 SPA 深链接回退和 `/api/*` 优先进入 Worker 的规则。
- 现有 CSP 不降低安全强度；如需显式声明 `manifest-src`，仅允许 `'self'`。不得为安装功能放开外部脚本、通配域名或内联脚本。
- 不引入 `vite-plugin-pwa`、Workbox 或同类缓存工具；本版通过静态清单、图标和少量安装交互代码实现。
- 不增加应用内自动刷新机制；重新打开或正常刷新时按现有资源加载策略获取新版本，不为更新强制打断编辑。名称、图标等安装元信息的更新节奏由浏览器控制。
- 发布继续遵循现有检查、备份和部署流程，不新增数据库 migration 或 Cloudflare Secrets。

## 7. 验收标准

### 7.1 自动检查

- Manifest 为有效 JSON，字段和图标尺寸符合本文要求；资源不包含固定生产域名、令牌或用户数据。
- 类型检查、构建通过；构建产物包含 manifest 和全部图标，页面引用正确。
- 安装交互覆盖可安装、无事件、取消、失败、独立窗口状态和事件监听清理；不自动弹提示。
- 浏览器回归覆盖登录、标题/正文编辑与保存、切换笔记及深链接刷新；安装提示取消不清空当前编辑内容。
- 没有新增 Service Worker 注册、离线缓存或后台同步逻辑。

### 7.2 必须人工验证

在实际 macOS Chrome 环境记录系统与浏览器版本，使用 HTTPS 测试部署完成：

1. 从笔记详情页安装，应用名称与图标正确；正常重新启动使用首页入口，不将该笔记固化为启动地址。
2. 用户能将图标固定到 Dock，关闭窗口后从该图标重新打开独立窗口。
3. 独立窗口中内部导航不跳回普通网页标签；外部链接不覆盖编辑现场。
4. 有效会话可正常使用，退出或会话失效后正确要求登录；不显示其他登录态的私人数据。
5. 标题/正文修改、表格操作、图片读取、自动保存及重新打开后的内容正常。
6. 无可用安装提示时手工指引可用；当前独立窗口不重复显示安装按钮。
7. 浅色/深色、窄窗口及 Dock 图标显示正常；新版本发布后正常重开/刷新可以加载新资源。

自动化模拟 standalone 或安装事件不能替代真实安装验收。未完成实际安装、Dock 启动和独立窗口验证时，不得声明本版完整交付。

- 对应测试、README 使用指引和实际安装验收记录。
- 不改动与本次安装目标无关的编辑器、数据库、鉴权或缓存机制。
