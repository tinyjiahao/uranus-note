# Uranus v5 实施记录

> 日期：2026-10-26。实现范围以 `plan_v5.md` 为准。本文件记录代码完成与实际自动化验证；真实系统剪贴板、IME、读屏和 macOS 安装窗口仍需人工验收。

## 已完成

- V5-01 / 03 / 04：正文行高改为 1.5，统一段落、列表、单元格间距与悬挂缩进；表格外边界回到正文起始线；列表标题/摘要/时间使用 14/12/11px 层级。
- V5-02：按后续反馈移除元信息栏的立即保存按钮。IndexedDB 草稿采用 800ms 防抖和持续输入 3 秒上限；远程默认 30 秒同步，设置支持 5–300 秒且仅此浏览器生效。失焦仅本机暂存；Cmd/Ctrl+S、切换笔记及显式元数据操作立即同步，后台退出尽力提交。沿用串行保存队列与冲突保护，区分本机暂存和服务器确认，网络恢复后重试暂时性失败；图片上传状态独立显示。
- V5-05：支持剪贴板图片文件、多图顺序上传、混合文字粘贴、同笔记图片引用复用和跨笔记附件复制；只含外部 URL 的图片不会被抓取，失败不会插入破图节点。
- V5-06 / 12：应用内链接对话框分离显示名称和地址，支持校验、编辑、移除；阅读模式单击打开，编辑模式提供操作条并支持 Cmd/Ctrl+单击。
- V5-09B：保留矩形服务端校验；外部短行表格粘贴时补空格，含 rowspan/colspan、嵌套或超限表格在修改正文前拒绝。既有插删行列、最后一格 Tab、撤销与刷新回归继续覆盖。
- V5-09A / 11：content schema 5 同步扩展客户端 schema、共享验证、API、草稿、历史、备份恢复和 D1 约束；单元格支持列表、待办、引用和代码块；`small` mark 可持久化，标题和代码中禁用。旧客户端覆盖 schema 5 返回 `CLIENT_UPDATE_REQUIRED`。
- V5-10：行内代码后增加代码块与复制代码入口；支持 Tab/Shift+Tab 两空格缩进、Cmd/Ctrl+Enter 退出、保存和历史往返。按后续反馈移除斜杠快捷菜单，输入 / 作为普通文本处理。
- V5-07：表格菜单提供浏览器级“显示行号”偏好；行号不进入正文、搜索或 revision。
- V5-08：manifest 与页面 theme-color 从品牌黄改为系统浅深模式对应的中性色，保留应用图标和内部强调色。
- V5-13：笔记内查找覆盖标题投影与正文，支持跨 mark 字面匹配、上一个/下一个、序号、Unicode 映射及滚动定位，查找输入保持焦点。
