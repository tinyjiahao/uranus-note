## 修复内容

- 打印只预加载与解码带 attachmentId 的真实图片，排除 ProseMirror 分隔图片；保留真实图片读取失败时的错误提示。
- 粘贴图片先验证来源：同源附件 URL 归一化后必须与 attachmentId 严格匹配，再复用当前笔记附件或复制其他笔记附件。外部图片拒绝插入，不发起外部图片请求。
- “更多格式与插入”菜单允许缩进命令主动交还编辑器焦点，避免重渲染时抢回焦点；其他弹层保留原有焦点恢复。
- 代码块 Tab 直接插入两个空格的文本事务，避免经过 HTML 解析丢失空白；组合输入与只读时不拦截。
- 搜索命中代码块时通过插件会话状态临时展开，不修改 collapsed 属性、revision 或撤销历史，随后滚动到实际命中。
- 笔记信息按连续链接范围计数，格式拆分不重复计数，块边界与非链接内容分隔后分别计数；文件选择器显式支持 .yaml。
- 恢复 plan_v1/plan_v2 历史需求、P2 与验收目标，并注明旧鉴权候选方案由 v6 替代。

## 测试调整

- 图片只查询 img[data-attachment-id]，排除编辑器装饰图片。
- 上传文件按 inlineFile 断言与查找附件 ID，继续验证跨笔记复制、持久化及 ZIP 导出错误处理。
- 代码块内容从编辑器文档读取，排除行号与按钮；辅助方法等待编辑器获得焦点，并把单个代码块的光标放在代码内，避免落入自动追加的尾部空段落。
- 长代码块搜索用例显式构建 151 行文档；不再依赖浏览器一次 insertText 多行构造测试数据。
- 新增 v8-regressions：行内与块级图片和行内文件混排打印、已有附件 ID 搭配外部 URL 的粘贴拒绝、折叠代码搜索临时展开。
- 登录超时已确认是共享测试账号触发身份维度限流；本地 fixture 观察登录的真实 429 响应，遵循 Retry-After（最多 60 秒）后重新点击登录一次，并延长该测试超时。其他鉴权错误不重试，非本地 URL 不启用该处理，服务端限流规则不变。使用 response 监听而非 page.route，保留浏览器 HTTP 缓存供附件缓存用例验证。
