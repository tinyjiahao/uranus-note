## v1 尚未达到的范围

- 跨笔记图片粘贴的客户端占位/重试流程、复杂 HTML/Word 粘贴白名单清洗和 `⇧⌘V` 专门处理尚未完成；服务端复制接口已存在。
- 草稿恢复已提供服务器版/本机版选择；配额统计、七天清理提醒尚未完成。v2 已补齐会话失效遮蔽、保存失败反馈和复制补救入口。
- 文件夹重命名/删除和笔记移动 UI 已提供；文件夹删除目前是有界原子批处理，不是规格要求的持久分批任务。
- multipart 上传采用严格 Content-Length 和 10MB 上限后的有界缓冲，尚未替换为增量 multipart 流解析；大并发内存基准未完成。
- 附件审计目前检查 D1→R2 缺失/长度，不扫描未知 R2 孤儿；人工修复选择接口未完成。
- 小于 60KB 的退出保存已使用 keepalive；beacon 备用端点、完整租约接管对账、附件复制独立固定回执，以及若干故障注入测试仍需补齐。
- 备份恢复具备可执行主流程，但尚未完成 20 篇历史图片抽样演练、断点进度文件和损坏/中断故障矩阵。
- 1,000/10,000 篇 staging 性能数据、staging 冒烟、真实自部署盲测与发布容量边界尚未完成。
- 当前样式为自托管 CSS，尚未迁移到规格选择的 Tailwind CSS。

因此当前版本不能标记为 v1 发布完成，也不能把上列项目作为已实现能力宣传。
