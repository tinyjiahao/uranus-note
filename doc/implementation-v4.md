# v4 最小安装支持实现与验收

日期：2026-10-26。代码已实现并部署；真实 macOS Chrome 安装与 Dock 操作尚未验收，不代表 v4 已完整交付。

## 实现范围

- `public/manifest.webmanifest`：固定同源身份 `/`，启动地址 `/`，`standalone`，不含生产域名或笔记信息。
- `public/icons/`：192/512 PNG、独立安全区 maskable 图标、180 PNG Apple Touch Icon；沿用现有 SVG 品牌，生成脚本为 `scripts/generate-install-icons.mjs`。
- 页面引入 manifest、PNG Apple 图标、品牌主题色；manifest 显式声明 MIME 和重新验证缓存策略。
- 应用启动时捕获安装事件，在设置打开前也可保留；事件仅存内存。消费一次、防重复点击、失败/取消回退、安装接受与完成区分、动态 standalone 检测及监听清理均有测试。
- “设置 → 关于与部署 → 安装应用”提供操作或手工指引。取消/失败后将焦点恢复到安装小节，不改变笔记内容。
- 已有编辑器链接默认 `_blank` 和 `noopener noreferrer nofollow` 保留，部署指引链接保持新窗口；未重写既有链接编辑行为。
- 未新增 Service Worker、离线缓存、后台同步、安装遥测、依赖、数据库迁移或鉴权改动。

## 本地验证

- 最终类型检查通过；19 个文件、44 项单元/Workers 集成测试通过；重新构建后的 Worker preview 全量 Chrome e2e 23 项通过（1.3 分钟），包含 3 项 v4 安装专项。`git diff --check` 通过。
- 首次回归因复用的预览服务退出而无效；第二次发现新测试对“新建笔记”按钮的定位有歧义，已修正为明确入口，最终全量复跑通过。不是忽略失败用例后汇总成功数。
- 测试运行环境：macOS 13.7.8，Chrome 155.0.8059.86，自动化浏览器为 headless。
- PNG 已生成并检查 maskable 实际图片，主体在安全区且背景铺满；浏览器测试读取各 PNG 头验证实际尺寸。
- 自动检查涵盖公开 manifest/图标、正确 MIME、页面引用、同源路径、无 Service Worker 注册、安装取消/失败后内容保持、standalone 模拟与登录。
- 安装测试使用合成浏览器事件；这些测试不代表操作系统安装成功，也不证明 Dock 固定和启动已验收。
- 构建仍有已有的前端 chunk 超过 500kB 提示，不影响构建成功；本次不扩大到拆包优化。
