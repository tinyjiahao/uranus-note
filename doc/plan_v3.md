# Uranus v3 — 交互体验优化需求规格

> 日期：2026-10-25。状态：供开发实施与验收的需求文档，不代表已实现。
> 来源：`ux_v1.md` 的 26 项本地走查建议；原始观察、测试限制保留在该文档，不将未实测风险当作已确认缺陷。
> 基线：在现有应用上增量改进。本文明确调整的交互以本文为准，其余继续遵循 plan_v1、plan_v2；当前内容 schema 保持 4，兼容读取 1/2/3。不得因此实施 v2 待确认的网页令牌轮换方案。

## 1. 目标、范围与交付定义

目标：让表格创建直观、对象操作就近且一致、工具栏有主次、窄屏可操作、状态可信。保留现有编辑与保存能力，不重新实现一套笔记系统。

### 1.1 v3 必须交付

- 表格矩形网格创建、自定义尺寸防错。
- 行、列、表格、单元格及图片的上下文入口与统一命令行为。
- 精简手柄、插入反馈、列宽量化、表格横向溢出提示、明确对齐作用域。
- 保持现有按钮顺序和独立入口的格式工具栏、笔记更多菜单、窄屏元信息栏与底部操作面板；格式工具栏不重新分组。
- 合并排序入口、列表就地菜单、去重摘要展示、搜索命中片段与状态反馈。
- 设置分层、只读界面精简、返回上下文保持、键盘与可访问性支持。
- 保存、图片、版本、并发与 schema 兼容回归。未知风险通过测试确认，不以“未实测”为由省略发布验证。

本版各实施阶段可分批部署，但只有全部必需项验收通过才能声明“v3 完成”。下面的优先级仅表示实施先后，不自动把项目排除出范围。

### 1.2 明确不包含

- 网页更新 API_TOKEN、D1 凭据摘要方案、SESSION_SECRET 编辑、Cloudflare 管理权限或资源切换。
- 合并单元格、电子表格公式、表格数据排序、任意复杂块嵌套、Excel 无损粘贴。
- 搜索结果点击后正文命中定位、跨会话逐篇阅读位置记忆、TSV 粘贴；继续保留为后续规划。本版包含搜索片段和列表返回位置保持。
- 多端 UI 偏好同步、独立手工标题字段、完整离线同步、自由拖拽全部布局分栏。
- 修改已确定的正文默认 14px 字号或新增内容格式；UI 整理不能削减已支持的 H1/H2/H3、图片、查找等能力。

## 3. 公共菜单、选区与可访问性协议

### 3.1 统一交互模型

- 所有入口先确定目标笔记/表格/行列/单元格/图片，再打开菜单。目标 id、编辑器选区与菜单锚点分开管理，不能根据菜单点击后的 DOM 焦点重新猜目标。
- 按钮、右键、Shift+F10 调用同一命令定义、权限判断、禁用原因和执行路径，不分别实现业务操作。
- 同时最多打开一个根弹层；允许其子菜单或确认对话框。开启设置、切换笔记、进入只读时关闭不再适用的菜单。
- 菜单打开期间保留编辑器选区；若正文变化使目标失效，关闭并提示，不把旧位置应用到另一个单元格。
- 插入、删除、清空等即时命令成功后关闭并将焦点返回合理编辑位置；对齐、宽度设置允许保持打开，并显示当前值。
- Escape 先关闭最内层；关闭菜单后焦点回触发者，触发者已删除时回编辑器合理位置。关闭未提交数值表单不自动应用。
- 外部点击关闭菜单，并尊重用户点击的新目标；不能强制把光标拉回旧位置。任何关闭操作不产生正文保存。

### 3.2 桌面与窄屏呈现

- 视口宽度 ≥768px：使用锚定弹出菜单；行列手柄锚定手柄，右键锚定指针，键盘锚定当前目标矩形。标准命令菜单目标宽 220—260px，项目高 32—36px，超出视口时翻转/限高滚动，距离边缘至少 8px。
- 视口宽度 <768px：表格/笔记对象菜单使用底部面板，显示对象标题，如“第 2 列”“已选 3 个单元格”，关闭按钮始终可见。内容区可滚动，面板原则上不超过可视区域高度的 60%，小高度时允许扩大以保证操作可达。
- 底部面板考虑安全区和软键盘后的可视区域；数值输入焦点进入时输入框与提交按钮保持可达。关闭恢复背景滚动；不能多层遮罩叠加。
- 桌面滚动时菜单随仍可见锚点移动，锚点完全离开视口时关闭；窄屏面板打开时锁定背景滚动但保留选中态。
- 下文尺寸为布局目标；200% 缩放、长文本与可访问性优先于固定尺寸，不以截断关键命令达成尺寸指标。

### 3.3 键盘、触屏和原生行为

- 菜单 Up/Down 移动、Enter 执行，子菜单提供合理 Left/Right/Escape 行为；菜单按钮有可访问名称、展开态及目标说明。表单字段仍可通过 Tab 操作。
- 隐藏手柄不得留在 Tab 顺序；工具栏键盘导航遵循现有按钮顺序，不因焦点管理重新分组。表格控件采用合理的组内导航，避免逐个经过几十个隐藏插入按钮。
- 触屏不依赖 hover；选中表格显示对象入口，主要触摸目标至少 44×44 CSS px，可通过扩大透明命中区实现。
- 普通正文保留浏览器原生右键。自定义菜单仅在明确对象区域处理，不能全页面 preventDefault。
- 本版自定义菜单不新增依赖剪贴板权限的剪切/复制/粘贴按钮；保留键盘及系统路径，并在帮助中说明，避免做不可用的伪菜单项。
- 中文 IME 组合输入期间不把 Enter 当作菜单确认，不拦截正常文字组合。读屏能获知选区、混合状态和错误；状态播报不逐键轰炸用户。

## 4. 表格创建

### 4.1 网格入口

- 工具栏保留一个直接表格入口，点击打开 6×6 小方格选择器，不再用 36 个 `1×1` 等文字按钮。
- 默认预选 2 行 × 2 列；hover 或键盘移动到目标格时高亮左上矩形，文字显示“3 行 × 4 列”。每格仍有可访问名称。
- 鼠标点击或 Enter 插入，成功关闭并聚焦首格；默认开启“包含表头”，表头计入总行数。触屏点格可直接插入，尺寸在对应格的可访问名称中清晰表达。
- 保留“自定义尺寸…”入口，展开后才显示行数、列数与“插入”按钮，不同时展示两套主提交操作。
- 工具栏入口锚定表格按钮；斜杠命令触发时锚定光标，窄屏采用底部面板。关闭或取消不插入内容，保留原选区。
- 表格单元格内禁止嵌套创建；入口禁用并说明“暂不支持嵌套表格”，不能用非法 JSON 留到保存时失败。

### 4.2 自定义尺寸与预算

- 本版新建自定义范围：1—100 行、1—30 列，均为正整数；范围是新建操作的 UI 上限，不拒绝读取既有更大合法表格。
- 显示范围及表头计数说明；空值、非整数、越界就地报错，保留输入，禁止提交。最终候选正文仍须满足共享节点数、深度和 UTF-8 大小预算，不因落在尺寸范围内就保证可创建。
- 不保存上次大尺寸为默认。通过共享校验预检最终文档，失败不修改编辑器，服务端仍为最终校验方。
- 验收：默认表头的 3×4 表格从工具栏起两次点击完成；键盘可完成等价任务，取消后正文与 revision 不变。

## 5. 对象菜单与命令语义

### 5.1 菜单内容

| 对象入口 | 首层命令 | 规则 |
| --- | --- | --- |
| 行手柄 | 上方插行、下方插行、清空所选行内容、删除所选行 | 不提供列操作标签页 |
| 列手柄 | 左侧插列、右侧插列、调整列宽、清空所选列内容、删除所选列 | 显示目标列编号或选中数量 |
| 表格左上角 | 追加行、追加列、表头开关、宽度模式、平均列宽、表格上/下方继续输入、删除表格 | 宽度参数在子面板展示；危险项分组 |
| 单元格右键/键盘菜单 | 行操作、列操作、单元格对齐、清空所选格、表格操作 | 行列结构操作为子菜单，不混入笔记管理 |
| 图片右键/图片操作入口 | 图片左/中/右对齐、恢复默认对齐、移除图片；格内图片另有“表格操作” | 操作图片节点，不暗中修改相邻段落或整列 |

直接行列菜单应允许从手柄起两次点击插入，不需要先切换“行 / 列 / 更多”标签。命令名称包含范围，例如“删除 2 列”；删除用危险色和分隔线，不把普通清空或关闭伪装成危险动作。

### 5.2 选区与结构操作

- 点击行/列手柄选择相应整行/整列。右键位于已选区域内时保留选择；位于外部则切换到目标格/图片。本版不新增不连续多选，仅支持连续矩形、整行或整列选区。
- 对单格或跨多格选择执行行列命令，作用于选区涉及的连续行/列；插入位于选区最前或最后边界，每次插入一行/一列，文案明确。
- 插入后保留原内容，新行不因紧邻表头而默认成为表头，新列继承合理邻列宽度；结构预算超限则拒绝并提示。
- 多格 Delete/Backspace 和“清空内容”保留格结构、列宽与对齐，只移除内容并补足合法空段落。普通文本选区按文本删除处理；不得把普通退格变成删除整表。
- 清空/删除含图片单元格时沿用附件引用管理，不立即删 R2 字节，不破坏历史图片。
- 删除普通行列直接执行且可撤销；删除最后一行/列视为整表删除，非空需确认，空表直接删除。取消确认不改变文档。
- 表格上/下方继续输入：相邻位置已有可用段落则聚焦；否则插入一个合法段落，支持撤销，不复制空行。
- 即时命令后焦点落在合理的剩余格或相邻段落，不跳到文档开头。追加、删除、清空各为一个逻辑撤销步骤。
- 若提供“撤销”提示按钮，只在对应操作仍是编辑器撤销栈顶部时可执行；后续输入后不能通过旧提示误撤销新输入。

### 5.3 只读及图片入口

- 只读/回收站不显示可执行的结构与图片修改菜单，保留系统复制及只读滚动；隐藏手柄，不因右键切回编辑态。
- 图片新增的上下文入口可通过选中后的可见按钮到达，不依赖长按或右键。图片选中态、缩放手柄与菜单触发不得抢占普通表格滚动。
- 恢复默认图片对齐清除已有 `imageAlign`：正文图片恢复居中，格内图片跟随单元格；不新增持久化属性。

## 6. 表格直接操作、列宽与对齐反馈

### 6.1 手柄与溢出

- 非活动表格隐藏装饰性手柄；hover、焦点或选中时显示相关对象手柄。菜单打开时维持目标可见，不因鼠标移入菜单而闪退。
- 行列边界提供插入线与加号提示，列宽拖动位于单元格内部边界，插入按钮位于表格外侧导轨，两者命中区不重叠。
- 选中行列显示轻量文字范围；不要用整圈高饱和控制点压过内容。
- 横向溢出时显示可操作的滚动条容器与左右边缘提示，提示仅在对应方向仍有隐藏内容时出现；不能只依赖操作系统自动隐藏滚动条。
- 手柄跟随表格横向/纵向滚动，表格菜单始终提供追加行/列作为屏外加号的替代。调整窗口不改写已保存宽度。

### 6.2 列宽

- 保持共享白名单 64—2000px；拖动一个边界仅改变该列，显示实时 `277 px` 提示，pointerup 完成，Escape/pointercancel/失焦取消并恢复起始值。
- 拖动预览不进入自动保存队列；完成只产生一次逻辑内容更新和一次撤销，版本快照继续按既有规则生成，不承诺每次拖动必有快照。
- 数值面板标明“第 N 列宽度（px）”；多列选择时标明“应用到所选 N 列”，混合值显示占位，提交后统一所选列，不影响其余列。
- “平均列宽”固定作用于整张表格，按当前总宽均分并满足下限；文案标为“平均分配整表列宽”。
- “恢复自适应”清除整表手动列宽并设置 fluid；“按列宽显示”使用当前布局计算后的有效列宽并设置 fixed，结果均可撤销。
- 触屏默认以横向滚动为主，列宽通过数值面板调整，不要求精确拖动细边线。

### 6.3 对齐作用域

- 普通文本光标或文本选区：顶栏对齐控制修改所涉段落/标题 `textAlign`；图片 NodeSelection：修改该图片 `imageAlign`；单元格矩形选择：修改所选格的对齐。按钮提示随对象更新。
- 表格菜单中的控件始终叫“单元格水平对齐 / 单元格垂直对齐”，使用三段按钮并显示当前值；多选值不同显示混合态。
- 段落或图片有显式对齐时，单元格对齐不覆盖它。面板说明“有独立对齐的内容保持原设置”；图片菜单的恢复默认可用于跟随单元格。
- 值继续使用 schema 4 已支持的白名单；只读保持显示。前端、服务端、历史预览与恢复一致，不能仅修改 CSS 达成交互效果。

## 7. 工具栏与响应式布局

### 7.1 桌面

- 编辑器顶部格式工具栏保持当前版本的按钮排列顺序和独立入口，不重新分组、不重排，不新增用于收纳原有按钮的“更多格式”或“插入”分组菜单。
- 标题、加粗/斜体/下划线/删除线/高亮/行内代码、对齐、列表、待办、引用、分隔线、链接、表格、图片等按当前呈现方式保留；不合并标题按钮为选择器，不合并三个对齐按钮，不把原有功能移入子菜单。
- 对齐按钮仍按 §6.3 根据图片、段落或单元格选区更新作用对象和提示，不因此改变按钮数量或顺序。直接表格按钮继续满足两次点击创建要求。
- 仅优化尺寸、命中区、提示、禁用/选中态和可访问性；保留既有分隔，不新增分组容器或分组标题。实施前记录当前工具栏截图作为顺序验收基线。
- 编辑面板宽度不足时保持原顺序并允许工具栏局部横向滚动，提供边缘渐隐或滚动提示；聚焦屏外按钮时将其滚入可见范围，不通过隐藏、重排或收纳按钮解决宽度问题。
- 笔记元信息栏保留保存状态、当前文件夹与轻量星标/置顶状态，删除移入“笔记更多”并分隔；历史、移动等有明确名称。

### 7.2 窄屏

- <768px 元信息首行保留返回、可截断的笔记标题/保存状态、更多。侧栏不可见时不重复出现“收起侧栏”。
- 窄屏格式栏与桌面保持同一按钮顺序和独立入口，不改成分组面板；320/375/390px 可在工具栏内部横向滚动，须明确提示尚有屏外按钮，并支持触摸和键盘访问全部按钮，不让整个页面横向溢出。
- 元信息正常一行布局，保存错误可另占提示区；不为强制一行隐藏关键错误。长标题省略，完整标题可查看。
- 移动、置顶、星标、历史和删除放入笔记更多；设置继续沿用左下角唯一入口，不覆盖正文光标或系统安全区。
- 软键盘出现时当前编辑行和打开的参数输入可见，固定栏不与底部面板竞争空间；需真机测试，不以仅调整 viewport 通过代替。

#### 补充：顶部标题编辑（2026-10-25）

- 桌面和窄屏顶部均提供可编辑的“笔记标题”，保存状态在同一行靠右、位于操作按钮之前，以次要文字显示；预留状态空间，避免保存中/已保存切换挤动标题。失败/冲突仍保留警示色与详细提示区，不是额外显示一份只读标题。格式栏按钮顺序不变。
- 不增加独立数据库标题字段：文档首个顶层段落/标题块在界面上移到顶部编辑，正文编辑器只展示其余节点；保存时合成为完整 TipTap JSON，继续使用同一保存队列、草稿、冲突处理与版本机制。未编辑时保留原块类型、属性和内联格式。
- 空笔记使用空标题块；标题为空时列表名称继续沿用已有首个非空文本回退规则，不把正文内容自动搬入标题输入框。以表格、列表、图片等复杂块开头的旧笔记完整保留正文，顶部可添加标题，不抽走单元格或列表项。
- 顶部标题 Enter 进入正文，Shift+Enter 保留换行；中文组合输入期间不提前跳转。长标题可在输入区滚动编辑，不撑宽页面。标题使用原生文本编辑的撤销，格式栏撤销仍作用于正文。
- 阅读模式、回收站中的标题只读。刷新、切换笔记、载入草稿及恢复历史后，标题和正文不能重复、丢失或相互覆盖。

### 7.3 视觉与命名

- 使用统一 SVG、尺寸、线宽和按钮状态；鼠标提示、可访问名称与触屏菜单名称一致。
- `MD` 改为有明确名称的“导入 Markdown”入口，不暗示切换 Markdown 模式。阅读/编辑、正文宽度按钮保留当前所在位置，通过提示区分其视图作用，不另外分组或移动。
- 保留默认 14px 及已存偏好；降低列表摘要/时间对比层级、简化边框、统一间距，但不降低文本可读性。
- 焦点可见但不为整个大面板绘制抢眼厚框；活动态、禁用态、混合态不只用颜色区分。

## 8. 笔记列表、搜索与返回

### 8.1 排序与就地菜单

- 将排序字段和方向合并为持续显示状态的按钮，如“更新时间 ↓”；弹层分字段和方向两组，字段变化沿用合法方向并更新清楚文案。
- 继续服务端全量候选排序再分页、置顶优先、同值 id 稳定排序；标题空值仅标题排序时置后，不改已有 API 参数。
- 列表项 hover/focus 显示省略号，触屏常有可见入口；右键和 Shift+F10 打开相同菜单。包含星标、置顶、移动、移入最近删除。
- 右键未打开笔记时只标明菜单目标，不自动切换编辑器；命令必须发送目标笔记 id 和其最新已知 revision，409 显示冲突，不误用当前笔记 revision。
- 对正在编辑的笔记执行管理操作进入现有串行队列；普通删除反馈“已移入最近删除 · 撤销”，恢复调用正式 API。回收站菜单替换为恢复和永久删除，后者必须确认，不提供无效编辑操作。

### 8.2 摘要去重

- 不新增标题字段。普通列表若摘要 trim 后与标题完全相同，隐藏重复摘要行；空内容显示“暂无内容”，有内容但无独立摘要时允许只显示标题和时间，不凭猜测显示“仅图片”。
- 已有正文派生能获取下一非空段落时优先使用下一段；本版不为去重全库扫描/回写正文，不改变历史笔记 revision/updated_at，不逐篇请求完整内容填列表。
- 本规则是展示去重，不删除用户实际重复段落；搜索时命中片段优先于普通摘要。

### 8.3 搜索结果解释

- 输入框有明确可访问名称“搜索标题和正文”、当前范围和清空按钮。显示正在搜索、无结果、失败三种不同反馈；旧请求结果不得覆盖新查询，加载中不能将旧列表伪装成当前结果。
- 保留 NFKC + 小写的字面子串语义，先范围过滤，再排序分页，不引入 FTS 或相关性排序。
- 扩展现有列表 DTO 的可选 `searchMatch`：`source: title|body`、`text`、`ranges`、`normalized: true`。无 q 不返回；`ranges` 使用返回 text 的 Unicode 码点半开区间，不是原始正文偏移。
- 从现有 normalized_title/normalized_text 产生有界片段，标题优先，否则首个正文命中；片段最多 200 个码点，必须完整包含最长 100 码点查询，前后省略号不计入 ranges。text 以规范化后的真实匹配文本展示，不假装保持原文大小写。
- 前端按纯文本及结构化高亮渲染，不接受服务端拼接 HTML。未能产生合法范围时不高亮，不将规范化偏移直接应用原文。
- 后端仅为返回页产生片段，不能返回整篇搜索文本或正文 JSON，不能在前端逐篇拉正文。保持 v1 查询预算与性能验收。
- 点击仍按当前逻辑打开笔记，不自动定位正文匹配；该能力属于后续版本。此 DTO 不用于推断正文位置。

### 8.4 返回与位置

- 同一浏览器会话内从窄屏编辑返回列表，恢复范围、搜索、排序和列表滚动锚点；数据变化使锚点消失时恢复最近合理位置。
- 切换排序/范围按既有规则重置分页；普通返回不无条件重置。虚拟列表使用笔记 id 和相对偏移定位，不只保存易失真的像素值。
- 恢复导航不抢编辑焦点、不强制覆盖草稿。不新增正文或搜索词到 localStorage 的持久化；查询上下文保留在受控内存，退出时清理。

## 9. 设置与只读体验

- 保留现有设置抽屉/移动端全屏设置，外观默认展开；安全、关于与部署采用可展开小节，标题持续可发现，无需新增多级设置路由。
- 字号、宽度、主题、布局、排序控件对齐且即时生效；附简短预览说明，标注仅此浏览器。设置修改不重新加载正文、不触发保存。
- 恢复默认偏好放在独立区域，明确不删除笔记、草稿或凭据；需要确认后执行，localStorage 失败提示仅本次生效。
- 安全小节继续说明网页换令牌未交付、部署端修改方法和影响；不新增不可用提交按钮，不展示秘密值。
- 服务状态保留“已绑定”与“实际探测”区别，不将本次未探测写入描述为健康保证。
- 只读隐藏格式栏和修改手柄，显示“阅读模式 · 返回编辑”，保留查找、字号/宽度与导航；回收站不提供直接返回编辑，必须先恢复笔记。
- 切换只读不重建编辑器内容、不清撤销栈或草稿；未提交内容按既有流程保存，不能将只读当作保存确认。只读仍不是安全权限。

## 10. 保存、内容与安全边界

- 800ms 防抖、edit_sequence 确认、IndexedDB 草稿、revision 乐观锁、operation_id 幂等继续有效；菜单入口不绕过这些机制。
- 保存状态区分：未保存、正在保存、已保存到服务器、未同步但已暂存本机、两处均未保存、冲突、登录过期。仅对应序号真正落盘才显示本机已暂存，错误给出可执行恢复入口。
- 纯 UI 操作不修改正文、更新时间或 revision；表格列宽/对齐/结构修改作为内容编辑保存。撤销提交已保存内容时仍需新的合法保存，不回退数据库 revision。
- schema 4 继续支持单元格段落和图片，不开放嵌套表格/列表。正常版本预览与恢复不丢列宽、段落对齐、图片对齐和附件引用；旧客户端不能覆盖新内容。
- 不新增 D1 表、不改已发布 migration。纯交互与可选响应字段不需要 content schema 5；若实现确需新增持久化属性，先更新规格及兼容方案，不暗中加字段。
- 保留 0003/0004/0005 的既有升级要求；部署前确认环境已应用所需迁移，不把本版无新增 migration 理解为新环境无需初始化。
- 仍只使用 DB/UPLOADS bindings，所有业务表/索引等带 uranus_ 前缀；不引入平台管理凭据、外部图像抓取或绕过鉴权的预览接口。
