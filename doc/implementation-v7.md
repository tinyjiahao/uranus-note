## 2. IME 证据与限制

修复前，CDP 模拟 `zheng` 组合输入并停顿 1800ms，捕获到 EditorView.setProps 被调用 **2 次**，以“组合期间不得刷新 props”为断言的结构性测试先红。该模拟未稳定复现实际 `zheng长` 残段，不能据此认定用户报告的文本损坏根因已确认。

修复后，同一路径 setProps 为 **0 次**；正文提交为“正文正常”，标题模拟为“标题”。独立 React 渲染计数用例确认本机落盘、远程保存状态流转不增加 NoteEditorView 渲染次数。原自动同步、断网重试与切换笔记用例纳入回归。
