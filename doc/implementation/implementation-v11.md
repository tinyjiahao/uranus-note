# v11 本地缓存实施记录

日期：2026-11-19。对应需求：[`plan_v11.md`](../plans/plan_v11.md)。本轮不新增依赖、内容 schema、D1 迁移或服务端缓存写入，不增加列表持久缓存、Service Worker 或离线编辑。

## 实施

- 详情 GET 支持 ETag / If-None-Match（含弱比较与多个候选值）；账号鉴权在路由之前执行，轻量 revision 查询保留 user_id 和 purge_pending 过滤。无条件 GET 直接读取完整行；条件失配后从实际详情行生成 ETag。200/304 和正常列表响应携带共享表示格式标识，API 维持 no-store。
- 审核正文/标题、星标/置顶/移动、软删除/恢复、文件夹删除、历史恢复和硬删除路径：均沿用现有 revision 更新；无正文变化的历史恢复保留原 revision，因为 NoteDetail 未改变。
- `noteCacheStore.ts` 独立保存已确认详情、容量元数据和持久化屏障，与 `uranus-drafts*` 完全分离。按账号限制 100 篇/50,000,000 字节，LRU 淘汰只扫描容量索引。单条超限跳过，配额错误淘汰后只重试一次；事务错误显式回滚。缓存格式、表示格式和正文格式分开校验，损坏副本删除后重取。
- `noteCache.ts` 统一请求合并、60 秒有效期、列表 revision 复用、条件请求和内存版本保护。校验时间采用请求发起时间，配合单调时钟；持久副本在每次身份激活后的首次使用必须无条件 GET。持久化失败不作为保存失败。
- 缓存启动预览只读，独立显示检查/未确认状态。查询首次成功后解除临时门槛；移动端和用户阅读偏好保留。窗口焦点、可见性恢复和联网事件触发按需校验，没有定时轮询。手动“检查笔记更新”绕过有效期。
- 保存、元数据和历史恢复响应只取完整 note.revision 写入服务器副本；不持久化 QueryClient、搜索片段或编辑器乐观内容。无 ETag 的写回保留空值。账号切换、清理及单篇删除通过内存身份代次和 IndexedDB 事务内屏障保护，迟到响应不能重新填充旧副本。
- BroadcastChannel 只发送账号/笔记/版本及失效通知；缺失广播时每次读取仍核对持久化屏障。跨标签页清理仅失效，不主动重新下载。退出清理本次账号集合，移除记住账号清理对应命名空间；清理失败保留不含正文的待清理偏好，并暂停持久缓存。
- 服务器正文更新使用独立的编辑器信号；保存状态更新仍不触发 NoteEditor 重渲染。后台更新在无未同步修改且非组合输入时应用，尽量保留滚动位置。有修改时保留保存队列基线并进入冲突；404 停止重试但保留草稿。恢复后的低 revision 或同 revision 不同正文标记基线不可信，并在已有草稿中保留该恢复标记（清理服务器副本不解除标记），需显式采用服务器版或保留本机内容，禁止自动重放。
- 设置提供按账号开启/关闭和清理；清理不触碰服务器数据、未同步草稿、最近打开或阅读位置，失败支持重试。新增提示提供中文/English。

## 生产验收中的 ETag 兼容修复

线上实测：压缩后的详情 200 返回弱 ETag（`W/"…"`），相同内容的 304 返回强 ETag（`"…"`）。两者符合 HTTP 弱比较规则，但原客户端逐字比较会误触发额外的无条件 GET。共享模块新增合法 entity-tag 的弱比较，客户端仍原样保存响应 ETag；表示格式、身份与读取屏障校验保持不变。新增回归验证一次 200 加一次 304 即完成校验，不再多发第三次 GET。
