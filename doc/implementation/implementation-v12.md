## 自然高度与表头吸顶（最新要求）

按用户反馈取消 70dvh 局部限高，表格完整展开并跟随正文滚动；同时在 NodeView 中监听滚动与尺寸变化，滚动事件直接更新真实表头纵向位移，尺寸变化通过 requestAnimationFrame 合并计算。表头和行号角格使用 translate3d 与 will-change 合成层，避免滚动处理再延后一帧；仅在数值或吸顶状态变化时写入样式与属性。位移写入非正文 wrapper 的 CSS 变量，不复制表头、不修改 JSON；表头受当前表格底部约束，横向滚动和列宽由原表格管理。打印取消位移，销毁时清理监听与待执行帧。开启行号时，首行左上角空白格同步吸顶并遮住滚过的行号；仅吸顶期间增加轻微底部阴影和细分隔线，打印取消阴影。

plan_v12 的 V12-08 与 AGENTS.md 已同步，此项替代下述历史实现中的局部滚动吸顶方案。类型检查、构建及 Chrome 回归通过：40 行表格自然高度、无内部纵向滚动、正文连续滚动吸顶、横向列对齐、390px 窄屏、整张表格滚出视口时表头退场、打印禁用位移。已查看深色主题截图。真实移动设备、Safari 和 IME 仍需人工验收。生产发布结果见文末。

## 与需求伪代码的差异

- 现有 `ids` API 受 `RECENT_NOTE_LIMIT=20` 限制，服务端未扩容。未命中索引的唯一 ID 每 20 个分批，因此请求上限为 `ceil(未命中 ID 数 / 20)`，重复链接不会重复取正文。账号代次与 AbortSignal 双重防止旧响应写回。
- 仅按相邻 URL 判断前进/回退会把正常的 A→B→A 点击误认成回退，且无法识别浏览器多步 POP。本实现使用 location key，应用按钮仍导航到明确的站内 URL；不读取浏览器私有 `history.state.idx`。
- 实际表头在 `tbody` 首行中，不是 `thead`；外层 `.tableWrapper` 已经是横向滚动容器。为保持横向滚动和纯 CSS 约束，含表头的长表格限制在 70dvh 的局部滚动区域，首行表头在该区域内吸顶，离开整张表格后自然移走。没有改变 TipTap DOM/schema；与原稿假定的编辑区整体滚动吸顶有所不同。手柄预留区保留，表头层级高于选中覆盖层。
- 信息面板大部分数值原本已启用等宽数字，补齐版本时间/计数及列表时间等展示位；正文不作全局处理。

### 插入笔记链接弹层视觉调整

按用户截图反馈，候选改为统一 38px 行高、笔记图标、单行省略与内边距；键盘焦点使用低对比填充和细内边框，避免粗外轮廓被滚动区裁切。搜索框整合搜索图标，标题区减弱分隔，触屏候选至少 44px。已核对通用 `ui-surfaces.css` 的覆盖关系，保留深浅主题、搜索零请求、键盘选择与索引失效行为。类型检查及现有弹层浏览器用例通过，截图检查覆盖深浅主题。

### Markdown 导出兼容修复

旧版 Markdown 导入只解析部分块结构，表格行、加粗和行内代码可能仍是普通文本；原导出器统一转义造成 `\|`、`\*\*` 等输出。导出现在识别旧段落形式的合法表格（列数匹配的标题/分隔行），连续输出表格行，保留完整加粗、删除线与行内代码源语法；单词内的下划线不再多余转义。未匹配符号、HTML、普通管道文本仍保留必要转义，代码块不变；不修改已保存内容。独立 Markdown 和 ZIP 共用此序列化器。新增源语法回归单测及实际浏览器下载验证通过。

### 插入链接排除当前笔记

`NoteEditor` 显式传入当前笔记 ID；本地候选过滤和服务端搜索降级均在数量上限前排除该 ID，插入动作也再次检查。同名其他笔记保留，账号共享标题索引及已有链接不变。已补充到 plan_v12 §3.2，标题索引单测覆盖排除顺序、同名与空查询；浏览器覆盖本地搜索、改名后排除以及超量降级过滤。旧链接插入回归用例改为独立目标笔记。


### 笔记链接节点选中与剪贴板

单击立即导航改为编辑时单击设置 NodeSelection，显式选中样式与打开按钮；右键选择节点，双击、修饰键单击及只读单击保留跳转。剪贴板复用 ProseMirror 序列化与原有粘贴校验，无正文结构变更。v12 浏览器用例已使用真实 Chrome 剪贴板验证复制 HTML、剪切/删除/撤销、跨笔记粘贴和打开按钮；导航回归通过，类型检查通过。需求同步至 plan_v12 §12（V12-11）。


### 链接选中态与操作弹层

链接使用细内边框和低对比选中背景，移除行内打开箭头。单击选中后在链接下方弹出普通链接同款 `link-actions-popup`，右键打开同一菜单（打开、复制、剪切、删除）；删除项单独分隔，只读隐藏修改操作，不可用目标禁用打开。弹层不抢走编辑器焦点，快捷键仍作用于所选节点。通过浏览器剪贴板事件复用 ProseMirror 富文本序列化，操作失败显示快捷键重试提示。类型检查与 Chrome 菜单复制/剪切、撤销、删除、跨笔记粘贴、打开及导航回归通过，已检查深浅主题截图。需求并入 plan_v12 §12.2。

### 吸顶滚动延迟优化（中间方案，由下述原生时间线方案替代）

针对快速滚动时表头局部裁切或跳动，去掉滚动事件中的额外 requestAnimationFrame 等待，直接更新位置；保留尺寸变化合帧处理，并补充 visualViewport 滚动监听及销毁清理。表头与行号角格使用合成层，不添加过渡动画；未变化的样式和属性不重复写入。类型检查、构建及 Chrome 回归通过，补充快速双向滚动事件同任务定位、滚轮双向滚动验证，保留窄屏、打印及表格底部边界检查。真实触控板惯性滚动与 Safari/iOS 仍待人工验证。

### 表头分离修复：原生滚动时间线

用户再次反馈表头与顶部出现空隙。上一轮同步 scroll 回调仍依赖主线程跟随异步滚动，不能仅靠减少一帧等待保证一致。现优先采用 ScrollTimeline + Web Animations，真实表头与行号角格共用编辑区滚动时间线，以线性关键帧限制在表格顶部和底部之间。几何或目标节点变化才重建动画；观察正文高度变化；销毁时取消动画。无额外表头副本，不修改正文或 schema。打印用重要规则禁用变换。

不支持 ScrollTimeline 的浏览器保留同步 scroll 回退，其惯性滚动表现仍受主线程调度影响。方案依据 [Chrome 官方滚动驱动动画文档](https://developer.chrome.com/docs/css-ui/scroll-driven-animations)。测试同时覆盖原生与禁用 ScrollTimeline 的回退路径；原生路径主动阻止应用 scroll 回调，确认滚轮确实改变位置后检查表头仍对齐，以区别于只验证滚动停止后的定位。真实 Safari/iOS 和触控板验收仍需用户设备确认。
